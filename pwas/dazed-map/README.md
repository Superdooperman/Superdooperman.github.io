# Dazed & Confused · Austin Film Map

Interactive map of filming locations from Richard Linklater’s *Dazed and Confused* (1993).

Live: https://superdooperman.github.io/pwas/dazed-map/

## Run

Open `index.html` in a browser, or serve locally:

```bash
cd ~/dazed-map
python3 -m http.server 8765
```

Then visit: http://localhost:8765

Desktop = sidebar + map. Mobile = full-screen map with a sliding locations list (`#mobile`).

## Features

- 19 locations (Austin + Georgetown + Seguin)
- Filter by category (iconic, school, hangouts, party, houses, outside Austin)
- Search scenes, characters, addresses
- Click list or map pins for scene notes + “today” status
- Directions links (Google Maps)
- Mobile-friendly drawer list

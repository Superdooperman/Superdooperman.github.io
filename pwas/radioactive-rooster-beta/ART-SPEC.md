# Radioactive Rooster: art spec (dual art mode)

The game has two art sets with **identical relative file names**:

- `art/pixel/`: the default. Monkey Island-style pixel art, generated by `python3 tools/pixel/build.py` (the code in `tools/pixel/` is the source).
- `art/fancy/`: the owner's high-res set. Drop files in. **No code changes are needed.**

The game picks each asset in this order: `art/<mode>/<id>.png` (fancy also accepts `.webp`), then `art/pixel/<id>.png`, then `art/placeholders/<old name>`. Any fancy file that's missing shows as pixel.
Switch sets with the **Art** button (header, Menu or title screen) or the **G** key. The choice is saved in `localStorage["rr-art-mode"]` and switches live without resetting the game.

## Scene coordinates
- Logical scene size: **320 × 180** (16:9). It's exactly 1/4 of the old 1280×720 plates, so the old fractional hotspots map 1:1.
- Hotspots, exits and pose points live in `data/script.js` as logical pixels (`rect: [x, y, w, h]`). Art never defines click areas. Keep objects roughly where the rects are (within about 8 px), or move the rect.
- Every image is scaled to its box in logical units whatever its file resolution. Pixel files draw with nearest-neighbor scaling and fancy files draw smooth.

## Rules
- Fancy files must keep the **exact aspect ratio**. Use a whole multiple of the logical size: 4× is recommended, and 6× is fine for backgrounds.
- Use transparent PNG (or WebP) for everything except backgrounds.
- Don't paint the hero into backgrounds. He's always a sprite or a portrait.
- Animation strips (future): frames in a grid as declared in `art/manifest.json` (`frames`, `grid`, `fps`). Fancy art uses the same grid with bigger cells.
- Pixel set: the noir palette in `tools/pixel/lib.py` (about 40 colors), ordered dithering, no anti-aliasing.
- Canon (README): stuffed googly eyes with wonky pupils, he sees through the beak's nostril holes, and the red underarm feathers show only when gliding. The Cock Gobbler is a hawk femme fatale per the box cover: golden-brown feather mask, hooked yellow beak, red lips, dark wing-cape, black opera gloves with gold cuffs, a cigarette holder.

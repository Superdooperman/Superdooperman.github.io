# art/in

Put a finished drawing here using the same filename as the placeholder it replaces.

`bg-fence.jpg` in this folder replaces `art/placeholders/bg-fence.jpg`. The game shows the placeholder immediately, then switches if this copy answers a HEAD request.

Backgrounds: 1280 by 720. Do not paint Radioactive Rooster into the room plates. NPCs can be painted in, LucasArts style.

Character PNGs need a transparent background. The stuffed eyes are part of the suit, with pupils aimed in different wonky directions. He sees through the beak nostrils. Red arm feathers only on a jump from height or a glide. The squat and the crow in this episode are not those poses.

Leave `art/concept/` as the original drawings. The filename list and the known problems with the placeholders are in `art/MANIFEST.md`.
